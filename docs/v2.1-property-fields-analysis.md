# v2.1 Property Fields — Isolated Analysis

**Generated:** 2026-08-26  
**Scope:** eligible DLD transactions and the existing verified-DLD-only Accuracy dataset.  
**Policy:** analysis-only; no evaluator, Accuracy artifact, calibration, weights, fallback policy, raw DLD file, or historical result was changed.

## Executive finding

The additional fields can now be captured safely in the UI and carried into the result explanation. **Project / Building Name is measurable from the actual DLD `masterProject` and `project` fields.** The current eligible DLD schema does not provide verified separate BUA, Plot Area, or Last Renovation Year fields. The existing `area` and `procedureArea` values must not be relabeled as BUA or Plot Area, so those three fields cannot yet support a fair Accuracy improvement experiment.

The zero counts above are based on explicit field names (`bua`, `builtUpArea`, `plotArea`, `landArea`, `lastRenovationYear`, and `renovationYear`). They do not imply that `area` or `procedureArea` are unusable; they mean only that those fields are not a verified split between built-up and land area and are not renovation records.

## Accuracy experiment status

A defensible comparison of **Accuracy, MAE, bias, P90 error, ±15% hit rate, coverage, and fallback transitions** requires a verified input-to-outcome mapping for each new field. Project cohorts can be constructed from DLD project labels, but BUA, Plot Area, and Last Renovation Year have zero verified coverage in both available datasets. Accordingly, the current runner stops at coverage and cohort diagnostics instead of producing synthetic values or rewriting official Accuracy results.

The next evidence requirement is a reliable source or governed mapping for the missing fields. Once supplied, the isolated experiment should compare the existing district fallback against a project-aware shadow cohort and report the requested metrics by property type. Any production evaluator or Accuracy change remains blocked until the owner reviews that evidence and explicitly approves it.
