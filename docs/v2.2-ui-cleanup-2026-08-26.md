# AQAR v2.2 Evaluation UI Cleanup — 2026-08-26

## Scope

This cleanup targets the public evaluation interface only. The official valuation calculation, method applicability, calibration weights, Accuracy artifact, fallback policy, shadow configuration, and observation payload contract remain unchanged.

## User-facing changes

The result card now keeps the estimated market value, range, confidence, and a concise **Why this valuation?** explanation. Individual valuation method cards, method names, method weights, method applicability, and technical calibration details are no longer rendered in the result card.

The word `DLD` was removed from visible evaluation-interface copy. User-facing labels now use neutral wording such as `Market Data`, `Comparable sales`, `Choose a project`, and `Market evidence`. Internal source identifiers and data-loading functions remain unchanged because they are implementation details and are not rendered to the user.

The top refresh and evaluated-record status line, the BETA banner, and other non-essential status copy were hidden from the public form. Internal elements used by existing status-update code remain in the DOM but are hidden.

## Verification

A local browser check confirmed that the initial visible page text contains no case-insensitive `DLD` occurrence. A synthetic result render confirmed that the result card contains **Why this valuation?**, contains no method or approach text, and contains no `DLD` text.

The result remains readable with the following user-facing information: estimated market value, range, confidence, comparable-sales count when available, evidence strength, market trend when available, natural market variation, and selected input adjustments.

Automated project tests remained at 78/78 passing. Inline JavaScript validation, the OSM function syntax check, and Git whitespace validation also passed.

## Not changed

No official valuation value, Accuracy calculation, calibration configuration, fallback behavior, project evidence logic, GIS behavior, or observation storage behavior was changed by this UI cleanup.
