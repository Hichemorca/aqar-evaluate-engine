# Archived project reports

This directory contains historical review and correction reports retained for traceability. These documents are not runtime inputs, calibration sources, or production artifacts.

| Document | Role |
|---|---|
| `AQAR-CORRECTION-REPORT.md` | Historical correction report. |
| `AQAR-PRE-CORRECTION-AUDIT.md` | Pre-correction audit record. |
| `AQAR-RULES-INVENTORY.md` | Historical rules inventory. |
| `Market_Intelligence_Scientific_Review_Final_Report.md` | Historical Market Intelligence review. |

When a report contains an older path, value, or recommendation, prefer the current source code and the current documentation under `docs/` and `README.md`. Do not use archived reports as a source for new calibration values or official data updates.
